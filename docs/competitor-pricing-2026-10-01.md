## 50台・50アカウントで比較するとき

LANSCOPE ベーシックのプランⅡは、ライセンス部分が50台×500円 = 月換算25,000円（年300,000円）。公式の初期費用30,000円/社を加えると、50台の初年は330,000円（オプション等別）。別条件のプランⅠは登録料50台×6,800円 + 年額50台×3,600円 = 初年520,000円、翌年以降のライセンス部分は年180,000円。単月解約できる月額契約として扱わない。ジョーシス国内販売 SaaSマネジメントは50 IDs×600円 = 月30,000円（年360,000円）。Nudge Essential は50アカウントでも最低 $750/月 = 仮に1ドル150円で112,500円/月（年$9,000）。海外 Josys 入口プランは枠内なら $100/月 = 同じ仮定で15,000円/月。為替は比較用仮定で実勢値ではない。各プランの最低数量、初期費用、税、対象機能、販売条件は正式見積もりで確認する。

この比較は国内外の近接市場で月数百円/台・ID、組織単位で数万円以上という価格設計があることを示す。AIミハルが各社製品を代替する、同等の検出率/保守品質を持つという証拠ではない。

## LP に掲載可能な案

現状の README は試験段階 OSS でホステッド SaaS・有償サポート未提供と明示している。今ある機能と未提供プランを分けて掲載する。

|---|---|---|
| 自社運用 OSS | ライセンス料 0円 | 提供中。Apache-2.0。自社のサーバー・導入・運用費は別。サポート/SLAは含まない |
| 商用プランの参考価格 | 月額500円/管理対象端末、最低月額15,000円（税別） | **検討中・現在申し込み不可**。30台以下15,000円、50台25,000円、100台50,000円。サーバー費・初期導入費は別。実装された範囲の可視化/台帳/予算/証跡を想定 |
| 個別要件の相談 | 個別相談 | 現在の対応可否を相談する窓口。実施契約、24時間監視、専任担当、第三者認証を既に提供していると約束しない |

LP の文案:

> 自社運用なら、ソフトウェアのライセンス料は0円。サーバーと運用はお客様でご用意ください。商用提供は検討中です。参考価格は月額500円/台、最低月額15,000円（税別、サーバー・初期導入費別）。現在、有償プランのお申し込みは受け付けていません。提供条件のご相談は株式会社世良（info@sera-inc.co.jp）まで。

料金案は競合の国内300–600円/台・IDレンジと海外入口プランを参考にした企画値であり、販売実績でも契約オファーでもない。顧客ゼロ段階では実測の保守負担と責任範囲が決まっていないため、「すべて込み」「無制限」「99.9%保証」「国内最安」等は掲載しない。公開料金カードには参考価格の直近に検討中の表示を置く。

根拠となる運用費は [クラウド比較](cost-comparison-2026-10-01.md)。50台の場合に顧客専用VM $24（仮換算3,600円）を別請求すると、参考料金25,000円 + インフラ3,600円 = 月28,600円、初期費用・税・追加保管等別。運用人件費を月2時間×5,000円と仮定すると10,000円が必要になるため、サーバー費だけで採算を判断しない。
