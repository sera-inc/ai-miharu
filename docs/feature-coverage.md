# 画面と機能の一覧（ポータル 18 画面）

**確認日**: 2026-09-30（初回）、2026-10-01（主要操作の追加検証）　**対象**: `portal/app/static/index.html` の `NAV` が定義する 18 画面と、ナビゲーション外の 3 画面。
**確認方法**: サンプルデータ入りのデモ（`demo/`）を実ブラウザー（Chromium、1440×900）で開き、画面の文言と操作を確認した。
「操作を確認」は、その操作を実際に行って画面が応答したもの。「表示を確認」は、ボタンや入力欄が画面にあることだけを確認したもの（押していない）。
2026-10-01 は合成データで設定保存・復元、個人アカウントの許容・未解決への復元、AI台帳の判断保存・既定値への復元、QA用登録トークンの発行・失効を実施した。SSO は合成 Microsoft Entra プロバイダーで確認し、外部の実テナントには接続していない。操作ごとの結果と証拠は [実行・回帰検証](runtime-verification-2026-10-01.md) を参照。その他の「表示を確認」の項目は、操作確認済みへ変更していない。

この表は、ランディングページ（株式会社世良のサイト）の機能紹介の根拠です。**表にない機能は、ランディングページにも書きません。**
画面の説明文は製品の日本語 UI の文言を出典にしており、この表の「限界・注意」も、画面上の説明と、`docs/` の対応する文書に書かれている内容だけを使っています。

## LP に載せない・載せ方を限った画面

- **設定の他のタブ**（受信サービスとログ保存先、表示とアラート、アカウント）: URL、シングルサインオンのテナント ID・クライアント ID、アカウントのメールアドレスなどの識別子を含むため、画像は掲載しない。デモ用の値であっても、実運用で同じ画面に実在の識別子が入るため、画面の説明だけを文章で載せる。
- **登録トークンの全文**: 画面に出るのは発行直後だけ。2026-10-01 の操作検証ではQA用トークンを発行して失効させたが、全文は撮影・掲載していない。LP 用画面は発行操作前に撮影し、画像に写るのは一覧の ID の先頭部分（デモ環境で自動生成された値）だけ。
- **実在の組織・個人の情報**: 画面のデータは、すべて架空の日本の姓による作り物のサンプルです。

## この一覧の使い方

- 機能の追加・削除・文言の変更があったら、この表と、LP の機能詳細（`SeraAiGovernanceFeatureDetails`）を同時に直す。
- 画面の説明が「できる」と書いている操作でも、この確認で押していないものは「表示を確認」にとどめている。実際に押して結果を確認した時点で「操作を確認」へ移す。
